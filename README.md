This reporitory is for codes and other work relating to the first module (Programming fundamentals for Marine Science) of subject MB5370 Techniques in Marine Science 1 taught at JCU.

The repositories contains two codes created in R. One is an R script and the second one an Rmd file. 
The first one (MB5370_W1.R) contains the coding of the first workshop of the module. 
The second one (MB5370_Workshop.Rmd) contains the coding of all four workshops related to the module.

The four workshops were divided as described below:
  - Workshop 1 - Foundations
  - Workshop 2 - Visualisation
  - Workshop 3 - Reproducible research in marine science
      * the code do not contain anything about this part as the work related to this task did not require coding. (It was focussed on the ability to link our work to GitHub)
  - Workshop 4 - The Developer's Toolbox & AI
